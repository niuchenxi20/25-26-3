Output dependency
& Antidependency
—I1: R3  R3 op R5
—I2: R4  R3 + 1
—I3: R3  R5 + 1
—I4: R7  R3 op R4
• Output dependency
— If I3 completes before I1, the result from I1 will be wrong -
output (write-after-write) dependency
• Write-After-Read dependency (Antidependency)
— I3 can not complete before I2 starts as I2 needs a value in R3
and I3 changes R3
• Antidependencies and output dependencies differ from true
data dependencies and resource conflicts. They are both
examples of storage conflicts.
