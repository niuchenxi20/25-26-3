# 东南大学信息学院大二下资料

> SEU School of Information Science and Engineering · Sophomore Semester 2 Course Materials

本仓库收录了东南大学信息科学与工程学院**大二下学期**（2025–2026 学年第二学期及短学期）课程的学习资料，包括历年真题、试卷、复习笔记、实验报告、课件与答案等，整理成仓库便于随时查阅与备份。

## 目录结构

| 文件夹 | 内容说明 |
| --- | --- |
| `中共党史` | 中共党史考试资料 |
| `书摘` | 读书笔记与摘抄 |
| `信号` | 信号与系统往年题、期中/期末试卷及复习资料 |
| `实践调研报告+10+…` | 社会实践调研报告（实现高水平科技自立自强——以电力行业为例） |
| `微机` | 微机系统与接口课件、小抄、期中试卷与复习资料 |
| `微机实验` | 微机实验报告、实验软件（DOSBox/MASM/TD）与教程 |
| `数模` | 数学建模与数学实验课件、MATLAB 实验代码与期末试卷 |
| `毛概` | 毛泽东思想概论课件、考点精编与复习要点 |
| `电磁场` | 电磁场与电磁波历年期中/期末真题与复习资料 |
| `计组` | 计算机组成原理课件、历年试卷与知识点总结 |
